# Landscape visual references

The phone landscape fixture follows the approved `landscape-calendar-real-sheets-v5.html` layout and renders the shared native Day View event faces. Its 852 × 393 viewport includes the phone safe-area insets.

The root image is the reviewed macOS reference. Linux x64 and ARM64 references were rendered with the pinned Flutter 3.35.3 toolchain in [App capture run 36482358634](https://github.com/JFil23/kemetic-calendar/actions/runs/36482358634), source commit `c9970091194afacecf45deebc7abaacaaf7cbc5b`. Both were visually checked against the root reference. Comparisons use exact pixels per renderer, with no tolerance or normalization.

The existing Ma’at portrait reference images remain unchanged.
