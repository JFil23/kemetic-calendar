# Onboarding decan wording — October 4, 2026

The supplied screenshot identifies Rekh-Nedjes 19. Day 19 is in the second
civil ten-day division (days 11–20); this is what the app's decanForDay computes.
Rekh-Nedjes and Phamenoth designate the same seventh month in different naming
traditions. UCL's Digital Egypt festival calendar explicitly equates
Rekehnedjes, Paenamenhotep and Coptic Phamenoth:
https://www.ucl.ac.uk/museums-static/digitalegypt/ideology/festivaldates.html

The phrase “dignity inside repetition” and its associated question are authored
reflection copy in DecanCompassCopyRepo, also eligible for the existing remote
copy override. They are not an attested historical definition of that decan.
The named star group ḥry-ib špsswt and its assignment to this civil division
could not be substantiated in the consulted scholarly decan database:
https://aea.physics.mcmaster.ca/index.php/en/database/decans
Absence of corroboration is not proof that the name never existed.

Onboarding therefore shows the civil calendar position using the same month
name as its date, then labels the existing question as a ḥꜣw reflection. It does
not assert the uncertain astronomical name or theme as historical fact. The
broader calendar metadata has not been audited or rewritten by this correction.
The five epagomenal days are described separately from the twelve months.
